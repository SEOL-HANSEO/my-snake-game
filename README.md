# 🐍 지렁이 게임 (Snake Game)

웹 브라우저에서 바로 즐길 수 있는 클래식 지렁이(스네이크) 게임입니다.

## 🎮 게임 소개
- 방향키 또는 WASD 키를 이용해 지렁이를 조작하여 사과를 먹습니다.
- 사과를 먹을 때마다 몸통이 길어지고 점수가 10점씩 올라갑니다.
- 벽이나 자신의 몸에 부딪히면 게임이 종료됩니다.
- 브라우저 로컬 저장소를 통해 최고 점수가 자동 기록됩니다.

## 🕹️ 조작 방법
- **이동**: 방향키 (`↑`, `↓`, `←`, `→`) 또는 `W`, `A`, `S`, `D`
- **시작 / 일시정지**: `Space` 키

## 🚀 실행 방법
별도의 설치 없이 `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)에서 바로 플레이할 수 있습니다.
